# ADR 0005 — GNU AGPLv3

O RetailFlow passa da licença MIT para a GNU AGPLv3. O texto jurídico está em [LICENSE](../../LICENSE). Este registro não resume as obrigações da licença.

Modificações e extensões que sejam obra derivada respeitam a AGPLv3.

A pasta `addons/` não prova, sozinha, que todo programa externo é obra derivada.

Exigência extra para um marketplace futuro fica num documento próprio.
