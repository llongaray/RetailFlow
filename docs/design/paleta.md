# Paleta

Os endereços do painel, do admin e da API estão em [Acessos](../../README.md#acessos).

`base_dir`: `docs/design`. Esta página é a única lista de cores do RetailFlow. O painel usa os tokens abaixo em `apps/web/src/styles.css`. O admin repete a mesma lista em `apps/admin/src/styles.css`.

| Token | Valor | Uso |
| --- | --- | --- |
| `--ink` | `#1c2420` | Texto principal |
| `--muted` | `#5d675f` | Texto secundário e rótulos de tabela |
| `--canvas` | `#f3efe6` | Fundo da aplicação |
| `--panel` | `#fffdf9` | Cartões |
| `--field` | `#ffffff` | Campos e botões neutros |
| `--line` | `#e2d9cb` | Bordas e divisórias |
| `--row-hover` | `#f7f1e6` | Realce da linha sob o ponteiro |
| `--sidebar` | `#14241c` | Barra lateral e login |
| `--sidebar-text` | `#d7e4dc` | Texto da barra |
| `--sidebar-active` | `#20362c` | Item ativo da navegação |
| `--brand-muted` | `#9fb1a6` | Legenda da marca |
| `--login-text` | `#edf4ef` | Texto do painel de entrada |
| `--accent` | `#0f766e` | Ação principal |
| `--accent-ink` | `#f4fffc` | Texto sobre a ação principal |
| `--gold` | `#a9782f` | Pendência e crédito em análise |
| `--danger` | `#8d3030` | Erro, rejeição e cancelamento |
| `--ok` | `#1f7a4d` | Conclusão e pagamento |

| `--pill-danger` | `#f8e6e6` | Fundo de status negativo |

| `--overlay` | `rgba(20, 36, 28, 0.45)` | Fundo do modal |
| `--toast` | `#14241c` | Aviso flutuante |
